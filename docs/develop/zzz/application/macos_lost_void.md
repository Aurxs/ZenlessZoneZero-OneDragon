# Mac 迷失之地

## 2026-10-28 商店刷新失效后的货币识别

本次7活性CoreML完整尝试在商店刷新后失败：09:37刷新按钮失效且费用图标消失，旧金币判据只读取刷新费用处，未将商品行明确金币作为后备。没有通关，真实周次数保持1，不能计为整局通过。

现由TemplateInfo从原始截图保存商品金币圆形模板，经画面CRUD维护四个商品价格图标区域；仅原刷新金币/血量都未命中时使用商品金币，不使用右上钱包判断商品支付方式。已识别血量仍按原开关退出，未知图标仍停止；价格、余额和实际扣款核对保持原逻辑。

4项聚焦检查覆盖刷新失效实拍、钱包金币不能放行、血量图标不能当金币、已识别血量不被后备覆盖。单独商店交易复验1670→670后返回通过；该诊断实例使用refresh_times=3，仅验证货币及交易路径，不代表原整局或真实刷新次数。随后用生产退出流程退局，仍保持周次数1，下一次须从大世界按原配置完整重跑。

截图在测试仓`screens/迷失之地-邦布商店/ios_gold_refresh_exhausted.webp`；本机原失败、分段交易和退出结果在`.debug/macos/coreml_full_lost_20261028/`及`.debug/macos/store_refresh_exhausted_20261028/`。

第二轮完整尝试10:10–10:19遇到折扣价组：划线原价和数字位数使金币图标横向移动，原窄区域未覆盖，仍在商店安全失败，周次数保持1。现由CRUD将区域改为四个完整商品价格槽位，阈值0.9不变；普通价/折扣价及钱包、血量负面检查共5项通过。当前页现价600/360独立解析，单独按原起始刷新参数0交易，4270→2590的实际扣款全部核对。

购物后四件商品均不可购、价格和购买按钮消失时，旧顺序会先把货币缺失判失败。现仅在四件商品完整且两帧均无价格、无购买按钮时返回；有购买按钮但价格/货币不明仍不放行。新增2项保护检查、当前空货架生产退出验证通过。分段仍不计完整通关，接下来必须从大世界重开。折扣及空态图为测试仓同目录`ios_gold_discount.webp`、`ios_store_no_buyable_goods.webp`。

复用原 `LostVoidApp`、应用设置、挑战配置与运行记录，Mac 只通过平台分支替换菜单和层间交互。战线肃清的8000悬赏闭环已在0活性、编队1完成原GUI连续验收，独立验收状态以[迁移进度](../macos_migration_progress.md)最新记录为准；开发局分段通关不能替代原GUI整链验收。

## 配置

| 参数 | 来源与语义 |
|---|---|
| 以太活性 | 原任务设置；-1维持游戏当前值，0至12指定档位；出战前读取实际值与上限 |
| 战略、周期增益、预备编队 | 原挑战配置；不把联调参数写进上游样例；编队1对应索引0 |
| 藏品、区域与金币购买优先级 | 原优先级解析、动态分类、购买开关与放行轮次 |
| 自动战斗 | 指定预备编队时优先该队保存的策略，使用当前编队时读取挑战配置的策略；开启自动转向须有Mac独立镜头校准，参数来自原灵敏度校准应用 |
| 完成条件 | 实际悬赏8000/8000、四档已领取并返回；本地已完成标记不能跳过真实领奖核对 |

本机日常偏好为7活性、编队1；0活性仅用于用户允许的独立验收。血量商店关闭购买时自动返回；开启血量购买、其他副本模式及未建档交互仍会明确停止，不能把金币商店通过扩大为所有购买路径通过。

## 原应用衔接

1. 原游戏准备确认输入模式，再由快捷手册进入迷失之地；读取实际悬赏分数。
2. 不足8000时选择战线肃清、调查战略、周期增益、实际活性和原预备编队，再出战。原应用持续调度层间移动，不依赖开发恢复入口。
3. 寻路复用原检测模型、区域优先级与脱困；Mac使用独立转向校准。对话、武备、鸣徽、卡牌、路径迭换和金币商店通过对应手柄操作处理，战斗沿用原上下文与逐帧HUD保护。
4. 道中结算核对完成关卡1/1及A确定。最终结算核对调查完成标识或S评级、正数结晶增量及B完成；返回入口确认后，原应用才增加通关次数。
5. 再读实际悬赏；不足则继续挑战，达到8000才打开领取。必须看到四档已领取，获得弹窗也只能确认一次，随后逐层返回主界面。领取失败不会被返回成功覆盖。

调查完成动画有明确标识后最多等待40秒，不把长动画当成可操作页面；普通未知画面仍停止并留图。暂停、停止和异常释放输入，局内失败时仅在已确认大世界打开战况暂停。GUI与联调桥不得同时持有采集或手柄。

## 对话和短暂OCR漏读

局内普通台词以底部面板与专属推进提示识别，右侧选项以唯一高亮和同行A识别；不维护台词/角色名单，也不要求正文或选项达到固定字数。OCR正文只用于判断同页是否取得进展。只在新帧且满足操作间隔时推进，同页三次未变化则停止。

单选卡片在同一页保留第一次按原优先级确定的目标，移动焦点后的短暂名称漏读不触发重新选目标；确认后候选名称减少也不单独作为换页证据。资源、购买与结算核验不受此放宽影响。
