# Mac 迷失之地抽奖机

`GamepadLostVoidLottery` 将原 `LostVoidLottery` 的剩余次数、通用奖励选择和返回流程映射到手柄。识别须命中原抽奖机返回及奖励预览双锚点，再读取移动端开始提示。

- 完整读取 `开始 剩余/总次数`，要求总次数为正、剩余不超过总数，且同一轮总数不变。每次开始须黄色按钮和同排左侧 A 提示，只发送一次，保留原 4 秒动画等待；必须确认分子实际减少一，才允许下一次。归零只按一次 B 并等待实际大世界，不把分母当成剩余机会。
- 获得战利品、鸣徽等继续委托现有通用选择和原优先级；已确认后见到抽奖机立即交回父流程，不能重复发送奖励确认。标准获得弹窗复用已有标题、黄色确认及选择提示检查。
- 原层间移动在加载后及交互阶段都路由抽奖机；成功后沿用原交互对象去重与出口搜索。

代表截图为测试仓 `screens/迷失之地-抽奖机/ios_one_remaining.webp`、`ios_zero_remaining.webp` 和 `ios_three_remaining.webp`。7 项次数与不重复输入检查通过，通用奖励交接有独立回归。生产 Operation 已在实际 3/3 页面连续完成三次抽取、三次通用奖励确认、逐次扣减核对和归零返回。原 GUI 整局仍未验收通过，组件完成不等于周活整链完成。
