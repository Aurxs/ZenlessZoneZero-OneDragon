# Mac 迷失之地抽奖机

`GamepadLostVoidLottery` 将原 `LostVoidLottery` 的剩余次数、通用奖励选择和返回流程映射到手柄。识别须命中原抽奖机返回及奖励预览双锚点，再读取移动端开始提示。

- 目前明确支持 `开始 1/1` 与 `开始 0/1`。前者须黄色按钮和同排左侧 A 提示后只确认一次，保留原 4 秒动画等待；后者只按一次 B 并等待实际大世界。其他计数或数字停止，不把分母当成剩余次数。
- 获得战利品、鸣徽等继续委托现有通用选择和原优先级；已确认后见到抽奖机立即交回父流程，不能重复发送奖励确认。标准获得弹窗复用已有标题、黄色确认及选择提示检查。
- 原层间移动在加载后及交互阶段都路由抽奖机；成功后沿用原交互对象去重与出口搜索。

代表截图为测试仓 `screens/迷失之地-抽奖机/ios_one_remaining.webp` 与 `ios_zero_remaining.webp`。5 项次数与不重复输入检查，以及通用奖励交接检查通过。实机分段完成开始、获得战利品及 0/1 返回；首次联调发现奖励交接缺口后补齐。尚待原 GUI 整局中连续验证，不能把分段恢复当作整链通过。
