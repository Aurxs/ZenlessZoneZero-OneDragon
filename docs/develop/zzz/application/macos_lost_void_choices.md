# Mac 迷失之地通用选择

`GamepadLostVoidChooseCommon` 负责手柄的鸣徽、卡牌与局中奖励武备选择，候选解析和优先级继续调用原 `LostVoidContext`。原任务接入和整链验收仍见[迁移进度](../macos_migration_progress.md)。

- 名称栏随卡片数量和类型改变。普通卡先定位实际黑色名称栏；双武备页使用原 GEAR 模板和武备名称区域。可选 `name_rects` 只限定识别范围，不改变原优先级；Windows 不传该参数时保持原区域。
- 单选先识别整卡黄色高亮，再移至原策略目标。普通鸣徽需要目标的“已选择”标记；双武备页无此标记，需要底栏 A 确定。提交后必须看到大世界或明确的下一交互，才返回父流程。
- 多选每次 A 后核对实际计数增加一和对应的新标记；“有同流派武备”不算已选。候选未读全时等待，不按剩余片段做决定。达到目标数量、标记数量一致且显示 X 确定时才提交；输入没有引起预期变化就停止，不重复盲按。
- 获得或升级提示与下一次选择分别交回父流程，不能沿用上一批候选和已选状态。

实拍归档在测试仓 `screens/迷失之地-通用选择/`：`ios_single_initial.webp`、`ios_multi_empty.webp`、`ios_multi_full.webp`、`ios_two_gears.webp`。覆盖单选移焦、仅确认一次、多选候选完整性、计数无变化保护及双武备 A 提示检查；目前已分段实机通过。此组件通过不代表整局、8000悬赏或原GUI独立验收通过。
