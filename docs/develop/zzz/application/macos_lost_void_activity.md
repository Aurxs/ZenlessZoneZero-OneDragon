# Mac 迷失之地以太活性

共同边界见[手柄迁移开发约定](../macos_gamepad_workflow.md)。原迷失之地任务设置新增以太活性选项，默认「维持游戏设置」（-1），可指定0至12；仅Mac战线肃清显示。使用原账户/任务组配置与YAML适配器。

`GamepadLostVoidSetActivity`读取专属栏的实际值与上限。保持设置或已经达到目标不发送输入；需要调整时核对行焦点及勾选模板，每次只改变一项，必须读到预期总值变化后才能继续，失败即停止。周期增益的单选圆标不能当活性勾选；依据面板标题先返回活性列表。

活动奖励预览的8000阴影结晶数据和悬赏进度8000/8000分别识别，预览不能证明周活完成。当前生产操作12→4、4→7以及再次读取7/12已通过；完整原任务尚在迁移，GUI任务仍灰显，不能将参数组件验收写成整链可用。实拍回放和配置范围检查位于独立测试仓`test/tools/macos/test_gamepad_lost_void_activity.py`，实际进度见[迁移进度](../macos_migration_progress.md)。
