# macOS 手柄地图传送

`GamepadTransport(ctx, area_name, tp_name)` 复用原传送的区域与地点参数，当前接入澄辉坪下的阿朔、汀曼咖啡和录像店营业点。该页其他区域、翻页与直接进入内部玩法的传送点暂不开放。画面与按键事实见[地图](../../../game/screens/地图.md)，传送点类型见[传送机制](../../../game/mechanics/传送.md)。

本机已通过正式 `GamepadTransport` 完整实测「阿朔旁大世界 → 普通地图 → 当前区域与底部传送点焦点 → 录像店营业点 → 传送确认 → 大世界」。落地画面可见阿甘名字左右的可交互尖括号。该结果确认了当前页录像店营业点的完整导航；汀曼咖啡与阿朔作为目标的正式完整传送仍分别按组件验收，不据此扩大实测范围。

操作从已确认的大世界或已打开的地图开始。大世界使用原游戏配置中的 `map` 动作，默认 Xbox 映射为方向右；地图读取当前区域黄边框及目标文字，按所在行列一次移动一个焦点。目标不在当前页就明确停止。A 进入底部后先识别小传送点框，再根据目标文字左右移动；大区域框同时高亮时仍以底部框为准。若地图保留了其他区域的底部焦点，先 B 返回区域层，再选目标。

底部小框上方 A 圆标会打断外轮廓，不能沿用副本列表的轮廓面积判断。独立识别函数限制卡片尺寸，并要求四边均有足够黄色像素；黄色商标与卡片内部图案不算焦点。每次方向键后必须看到焦点变化，未变化时只等待；进入底部、请求弹窗、确认传送都只发送一次 A。

确认阶段同时要求地图专属主句和确认按钮的黄色填充，不用单独「确认」文字放行。运行前已有不明目标的确认弹窗会停止。加载完成后需识别大世界快捷手册锚点才报告落地。Operation 负责有限重试、超时和原应用暂停/停止；本操作不使用 CUA、坐标点击、鼠标或键盘。

平台差异只新增在 `ios_gamepad` 的地图 patch，PC 画面配置保持原样。离线测试用实拍 webp 与对应 OCR 快照回放焦点导航，检验一次性确认、大小框优先级、目标不可见和按钮无高亮时不继续。最终支持状态仍以各地点实机执行结果为准。
