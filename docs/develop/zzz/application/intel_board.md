# 情报板

基础流程 (每周重置记录)

1. 发布委托
2. 挑战
3. 接收奖励

## 1.发布委托

### 1.1.恶名狩猎

1. 下述情况跳过
   - 开关未开启
   - 达到委托并行上限
   - 达到委托发布次数上限
   - 电量不足
2. 发布选择 3选1
    - 按恶名狩猎计划发布
    - 按体力计划发布
    - 自定义次数发布

### 1.2.专业挑战室

1. 下述情况跳过
   - 开关未开启
   - 达到委托并行上限
   - 达到委托发布次数上限
   - 电量不足
2. 发布选择 2选1
    - 按体力计划发布
    - 自定义次数发布

## 2.挑战

在未达到周期上限时，按配置选择委托进行挑战。

## 3.接收奖励

1. 接收委托奖励
2. 按配置优先级进行兑换
## Mac 手柄开发检查点（2026-10-28）

原 `IntelBoardApp` 已接入平台分支，配置和周记录仍使用原工厂。新增流程位于 `operation/gamepad/intel_board.py`；功能导览独立复用，移动端区域经平台画面 CRUD 保存，PC 区域保留。

- LT＋菜单键打开功能导览，按名字和整卡黄框进入情报板。
- 重置后选恶名狩猎和专业挑战室，分别识别黄色焦点和蓝色选中；列表只接取战斗代行，保留原自己的帖子过滤。
- 当前编队、预备编队序号、队伍策略和刷经验开关均沿原配置；预备编队委托既有 Mac 选择器，不替换保存的计划。
- 前往按钮必须聚焦，不能误按放弃；专业挑战核对代行 ON、实际消耗 00，恶名无报酬模式另核对深度追猎 OFF。
- 复用原策略、距离模型和战前移动。新增三卡鸣徽手柄选择，原序号保持；选择失败不能沿旧兜底边误报接敌成功。
- HUD 消失先停止战斗输入，读取通关目标 1/1 或 0/1。结果窄行 OCR 漏检时使用全帧 OCR 后限定原目标区域；标题本身不能证明胜利。
- 胜利结算、代行奖励和板面返回均确认后才增加原计数。失败不增加次数，并沿已知返回标识退出；未知页面留图停止，不盲按 A。
