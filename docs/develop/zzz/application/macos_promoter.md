## 选择规则

按原日期奇偶排列两个配置候选；先找第一候选，扫描两个方向仍不可用时才找第二候选，不替换为其他人。名称与唯一黄色卡框联合定位，名单名称不清时可读左侧大字详情或使用原头像特征定位。已观察到的“柚叶”简称映射为配置中的“浮波柚叶”，不模糊猜其他人名。

已有合法宣传员但不符合配置时重新进入列表，不能把“已有人”直接当成目标完成。确认前重新核对指定焦点；沿原 `press_shop_action` 按 A 后，必须在经营主页读到同一人物。正在营业时拒绝移动/确认，不解除营业或改保存配置来制造条件。
