# Mac 共用战斗引导处理

`GamepadBattleGuide` 是手柄操作共用的可选弹窗处理器，当前接入恶名狩猎战前移动，适用于各 Boss 的同类“战斗引导”页面，不依赖 Boss 名、招式内容或固定两页假设。没有弹窗时直接继续原流程，不等待引导出现。

使用 `画面-通用` 的标题、页码和返回提示识别。当前页小于总页数时按右方向键，到最后一页再按 B。页码不清晰时等待；同一页最多发送三次输入，失败保留现场。页码变化后重新计数，弹窗消失后清空状态。调用者应在普通移动/菜单输入阶段调用，不得与自动战斗线程并发发送输入。

库萨里库现场已验证两页引导需要先翻页再返回。最小测试覆盖缺席、多页、未知页码和卡页；其他 Boss 的弹窗尚待自然遇到时实测。自动战斗期间的弹窗恢复尚未接入，不能据此宣称完整恶名狩猎已通过。
