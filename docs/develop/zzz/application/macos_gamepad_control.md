# 设置 → 手柄

Mac 的手柄服务、动作按键和界面快捷键集中到“设置 → 手柄”二级页。“游戏设置”保留平台、游戏路径、窗口采集及界面操作间隔。Windows 原页面保留。

## 手动控制

操作区按用户提供的参考图绘制 Xbox 正面：深色半实心外壳、非对称双摇杆、圆形凹槽、一体十字键、紧凑 ABXY、视图/菜单/分享/Home 按钮，以及上方竖向 LT/RT 和短 LB/RB。采用 Qt 矢量绘制，按钮和背景共用缩放坐标，按下为蓝色高亮，不加载位图或浏览器。

1. 首次先用原“一条龙 → 准备游戏”确认手柄模式。
2. 打开“设置 → 手柄”，点击“启用手动控制”。它连接原账户控制器并占用原应用运行状态，不导航或改变当前游戏页面。
3. 按住/松开按钮对应实际手柄按下/释放；左键拖动摇杆控制方向和幅度，右键摇杆对应 L3/R3。下方快捷操作使用当前账户保存的组合键。
4. “释放全部”归零且保留会话；“结束手动控制”、离开页面或关闭窗口撤回请求并停止。应用失焦只释放保持输入。

原运行调度注册固定内部应用 `manual_gamepad`，不加入一条龙列表，也不对 CLI 开放。手动/自动共用一个控制器，启动初始化加锁；页面在连接、运行和清理完成前锁住映射/服务设置，撤回启动请求后不能立即重启或换参数。暂停、停止、失帧及断线继续使用既有输入保护，未改 OJD/HID 或 Windows 输入底层。

## 映射

- “动作按键映射”沿用原 `xbox_key_*` 和单次按键时长；“界面快捷键”沿用原 `xbox_action_*`。
- 原账户 YAML 与 `YamlConfigAdapter` 保持不变。修改后重建当前控制器，使缓存的动作映射更新；重复打开和账户切换仅回读，不自动保存或连接。
- 映射决定一条龙发送什么按键，必须与游戏内设置一致；图上的 A/B/X/Y 始终代表物理按键。未增加全局键盘模拟手柄。
