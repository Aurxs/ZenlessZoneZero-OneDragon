# Mac 迷失之地邦布商店

`GamepadLostVoidBangbooStore` 复用原 `LostVoidBangbooStore` 的商品、价格识别和原藏品优先级。金币购买开关、优先级放行轮次和追新配置来自原挑战配置。Windows 原操作不变。

手柄左右移至目标商品，核对唯一卡片外框与 A 购买高亮后提交。刷新仅在实际 RS 提示、可用按钮、刷新费用和余额均确认时执行。每次购买或刷新后读取右上余额，只有扣款恰好等于已确认费用才开始下一笔；未响应不会重发交易。

商品价格读取未经颜色过滤的完整数字。原白色过滤可能丢掉抗锯齿的末位零，例如1000误读成100；不能用旧价格补齐本轮缺失值，也不能放宽扣款校验来掩盖价格识别问题。余额动画先等待稳定，同一非预期余额重复出现仍停止留图。

购买弹窗只显示“是否确认购买此商品”，不含商品名；目标须在发起购买前核对。`GamepadLostVoidStoreConfirm` 依据交易类型、黄色确认与 A 选择提示确认一次。获得武备等子态交给新的通用选择操作，避免沿用上一笔选择状态。没有可负担商品后 B 返回，等待实际局内画面。

初次进入商店若已出现购买确认，而组件没有发起这笔交易，先核对完整弹窗和A提示，移至取消并确认；返回商店后重新按原优先级选择，不能接受未核对的默认商品。额外弹窗恢复有次数上限。层间交互在首个A后等待菜单响应，避免动画期间追加A。

2026-10-27 开发局已分段完成金币商店的刷新、购买确认、扣款核对和返回。代表截图位于测试仓 `screens/迷失之地-邦布商店/ios_gold_store.webp`、`ios_purchase_confirm.webp`、`ios_full_price.webp`。最小检查覆盖完整价格、精确扣款、余额动画、异常变化、未响应防重发与确认提示。血量商店开启购买时尚待实际画面适配，会停止留图；配置关闭的购买按原意直接返回。此组件通过不代表整局或8000悬赏验收完成。
