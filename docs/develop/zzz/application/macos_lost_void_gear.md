# Mac 迷失之地初始武备

沿用原`LostVoidChooseGear`的CV槽位/等级识别、武备名称解析和`LostVoidContext.get_artifact_by_priority`决策。Mac组件仅用方向键预览实际焦点，再按原追新配置与优先级选择；不通过坐标点击，也不固定首项。共同边界见[手柄迁移开发约定](../macos_gamepad_workflow.md)。

列表可以首尾循环，起点必须以可见首槽与唯一高亮外环核对，不能通过边界无响应判断。每个预览都重新读`[分类]名称`；同一轮收集完再定位目标。初始确认必须包含同一武备名称和唯一黄色确认按钮，确认后等待菜单关闭，再B返回局内。进入局内的正面特征确认后，才把本画面首槽名称记入原入口层共享名单；重复画面B返回，不重复携带。

无有效截图、焦点不唯一或名字缺失只等待。连接超时复用已支持的`GamepadReconnect`，继续连接后重新识别页面。旧参数和Windows流程保持原样。
