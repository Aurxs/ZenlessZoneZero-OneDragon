# Mac 手柄迁移开发约定

适用于本仓库的 PlayCover 手柄路径迁移与调试。当前完成范围看[迁移进度](macos_migration_progress.md)，具体键位与画面看 `docs/game/`；本文件只维护共同开发习惯。

1. **先复用，再适配。** 先读原 Application（任务）、Operation（流程节点）、配置、玩法和画面资料，把点击的目的转换为手柄路径。保留原 GUI、计划、运行记录、识别和战斗策略；只补 Mac 导航与画面差异，不另建任务体系，不重写底层 Windows、OJD 或 HID 输入。
2. **先确认输入模式。** 移动端手柄与触屏布局不同，切手柄后触屏失效。先由已有准备游戏流程确认手柄模式，再识别和开发路径；不能拿触屏截图定位手柄界面。启动阶段必要点击走已有独立启动适配层，不在任务中静默回退到系统键鼠。
3. **先映射代码，再逐项实测。** 已有资料足够就实现；只为未知手柄提示、默认焦点、特殊操作和失败画面补现场观察，不把整项任务手动重走作为前提。界面映射与实测由主代理负责，未经用户要求不另开代理或线程。
4. **按动作目的映射。** 打开页面使用已确认的快捷键；列表选择识别目标和焦点后有限移动；确认、领取、返回按页面提示执行。坐标只能限定稳定搜索区域，不做通用“点击坐标→手柄键”换算。目标、难度、编队和次数来自原 GUI 配置，不用联调值替换用户计划。
5. **识别常态特征。** 优先稳定标题、图标、按键提示和焦点，不依赖随机台词、卦象、奖励数量或随镜头移动的 NPC 姓名。OCR、模板与颜色识别按需要组合，不强求每一步 OCR，也不看到弹窗就一律按 A。
6. **短连招配关键检查。** 起点和焦点已确认的短操作可连续执行，保留动画等待；传送、进入功能、出战、领奖结果和返回处检查。未知焦点、可选弹窗和不定时加载再拆节点，不把整项任务写成长串固定按键。可选引导遇到才处理，读到最后一页再返回，不设为必经步骤。
7. **等待、重试与超时一起设计。** 界面步骤复用可配置最小间隔，保留已有更长等待；不拖慢自动战斗或拆开组合键。按键未响应时，只有新帧仍确认原页面才有限重试。父节点超时要覆盖子 Operation、动画与配置间隔，避免子流程完成后父流程误超时。具体实现见[公共等待说明](application/macos_predefined_team.md#界面操作间隔)。
8. **生产代码完成游戏动作。** 通过原应用或生产 Operation 实测；Computer Use 用于观察游戏和操作一条龙 GUI，不手动发手柄键补完失败步骤。GUI 与联调进程只保留一个采集/手柄持有者；命令行联调必须持续处理 Cocoa 主线程事件，不能照搬普通阻塞 Python 脚本。
9. **保护次数与真实结果。** 每日一次、每周限次任务先保存前态，再由代码消耗机会。分别记录首次领取、已领取跳过、分段恢复与完整连续通过；缺机会就标待验证。胜利和实际次数/资源变化确认后才累计，失败不得记成功。未知页面停止并留图，不盲按，不自动补资源；暂停、停止、异常都释放输入。
10. **小步完成并交付。** 只测改动直接影响的行为，使用独立测试仓和已有截图，避免重复已通过检查。完整可运行组件通过后单独 commit，两仓改动配对提交；不提交半成品，不把所有功能攒成一个提交。同步当前进度与适配提示，尚未支持的功能灰显或明确拦截。

开始自定义体力材料迁移，直接看[具体开发起点](macos_daily_routine.md#下一阶段更换体力材料与副本)。

## 两台 Mac 与 NAS 同步

两台机器分别维护自己的主仓和 `zzz-od-test` Git 元数据，代码只通过个人 GitHub 仓库交换。MacBook 的 `Program` 可以继续与 NAS 同步，Mac mini 的 `Program` 不接入该同步任务；不能同时用 NAS 和 Git 更新两台机器的源码。保留的文件同步任务排除 `.git` 文件和目录，包括测试仓及工作树的 `.git`；只写 `.gitignore` 不能阻止 NAS 同步。两仓使用同名分支，推送前核对 `origin` 为个人仓库、`upstream` 为上游。

整理同步冲突前先暂停两端同步，在同步目录外备份 Git 元数据、未提交文件、stash 和本机配置，分别核对 HEAD、暂存区与磁盘内容。跨机器路径出现在 worktree 记录中，或同一路径同时显示暂存删除与未跟踪时，不直接提交这些差异。若已发布提交整合了本地多次提交，先比较代码内容，保留旧历史备份后再对齐，不能只按 ahead/behind 数量判断功能缺失。

私有验收截图与 JSON 保留在各自机器，按确切路径写入各自 `.git/info/exclude`；部署启动器和机器说明同样本地保留。未完成草稿归档到同步目录外，不混入正式测试或发布历史。账户、设备路径、运行记录及缓存不随代码拉取覆盖。修改绿联云过滤规则后须再次核实暂停状态：保存设置可能自动恢复同步。解除 Mac mini 同步只删除同步任务，不能删除 NAS 文件；确认解除后才能清理 Mac mini 的本地目录或恢复 MacBook 同步。
