# 情报板

## 入口与状态流转

从[功能导览](功能导览.md)选择情报板，进入顶部“推送 / 情报板 / 日程”页面。玩法机制见[情报板](../gameplay/情报板.md)。

| 子态 | 入口与出口 |
|---|---|
| 委托列表 | LT 在卡片与底部刷新/筛选之间切换；方向键移焦，A 打开卡片；B 返回 |
| 委托筛选 | 底部选筛选后 A；Y 重置，方向键移焦条件，A 切换选中，B 关闭并保留条件 |
| 可接取详情 | 列表卡片 A → 详情；A 接取委托，B 关闭 |
| 进行中详情 | 接取后显示倒计时、放弃委托和前往；明确移焦“前往”后 A 进入挑战入口；B 关闭，不放弃委托 |
| 代行挑战入口 | 显示委托代行中 ON；专业挑战显示下一步和实际电量消耗，恶名无免费奖励次数时显示无报酬模式；START 进入编队 |
| 代行说明 | 编队 START 出战后可能出现；固定说明无法获得常规报酬，黄色确认 A 关闭；X 的“不再提示”是另一个开关 |
| 挑战结果 | 战斗结束 → 通关目标实际 1/1 或 0/1；B 完成后返回委托流程 |
| 代行委托完成 | 挑战结算完成后显示贡献点数与站点信度，黄色确认 A 关闭 → 委托列表 |

## 稳定特征与交互

- 列表底部有“周期内可获取”及动态 `当前值/1000`，右侧为点数兑换、委托管理和发布委托；它们不等同于代行接取按钮。
- 当前卡片是完整黄色边框，卡片顶部的“专业挑战室 / 恶名狩猎 / 困难委托”是类型标签。卡片高低不同，不能把屏幕坐标直接转换成方向键。
- LT 进入底部功能时圆形按钮填充黄色；筛选已应用且焦点在列表时，筛选图标填充蓝色。背景卡片可能保留轮廓，选择前还须区分底部焦点。
- 筛选面板标题“委托筛选”，上方为站点，下面为委托目标。黄色边框是焦点，蓝色填充是已选中；不能把二者当成同一状态。
- 进行中详情有“放弃委托 / 前往”两个按钮。第一次方向键可能先聚焦左侧放弃，只有前往自身黄色填充才可确认。
- 代行入口必须核对“委托代行中 ON”和实际无消耗模式；普通专业挑战、免费恶名奖励、深度追猎属于不同业务条件。

## 识别快照

完整 OCR、匹配区域、坐标和置信度保存在测试仓 `screens/情报板/ios_ocr.json`，各项与下方截图名一致。初始全局匹配可能包含不相关的模糊命中，运行流程使用本页固定局部区域和组合条件。

### 1. 列表（screens/情报板/ios_list.webp）

核心 OCR 为情报板、困难委托、专业挑战室、恶名狩猎、周期内可获取、点数兑换、委托管理、发布委托。原点数兑换和刷新模板分别约 0.994/0.965；平台新增列表标识位于 `[185,1015,345,1070]`，进度文本沿用原区域。帖子名称、玩家、时限、进度和奖励数字是动态值。

### 2. 筛选（screens/情报板/ios_filter_selected.webp；screens/情报板/ios_filter_two_types.webp）

核心 OCR 为委托筛选、委托发布时间、对应站点、委托目标、恶名狩猎、专业挑战室、困难委托、重置；标题约 1.000。“手柄-筛选条件”区域内以黄色边框与蓝色填充分别识别焦点、选中态。前一截图只选中恶名，后一截图两类均已选中。

### 3. 零消耗入口（screens/情报板/ios_zero_charge.webp）

可见委托代行中 ON、本次作战无常规报酬、下一步及实际消耗 00。关卡、挑战等级和燃竭状态属于委托指定信息；无消耗以代行模式和画面实际数值判断。

### 4. 出战说明（screens/情报板/ios_delegation_notice.webp）

核心 OCR 为委托代行中、代行委托专属的行动模式、完成挑战后无法获得常规报酬、但是可以完成代行委托、不再提示、确认、A 选择。标题与说明、黄色确认按钮共同识别，不能只见“确认”就按 A。

### 5. 专业挑战结算（screens/情报板/ios_expert_victory.webp）

核心 OCR 为挑战结果、完成专业挑战、实际 1/1、总计用时、B 完成。恶名失败另见 `screens/情报板/ios_hunt_failure.webp`：完成恶名狩猎 0/1，底部 B 退出；失败退出先回挑战入口，再逐层返回。专业挑战结算使用“专业挑战”，委托详情使用“专业挑战室”；识别须兼容这个稳定文字差异。

### 6. 代行奖励（screens/情报板/ios_commission_reward.webp）

核心 OCR 为代行委托完成、贡献点数、站点信度、确认、A 选择。固定标题与黄色确认按钮共同识别，奖励文字说明收益；不能误认成通用获得弹窗。

## 备注

发布、兑换、困难委托和所有站点的详细条件未在本次建档。接取失败、委托过期及无帖子等条件态仍需现场快照，不以任意弹窗按 A 兜底。迁移与验收见[开发说明](../../develop/zzz/application/intel_board.md)。
