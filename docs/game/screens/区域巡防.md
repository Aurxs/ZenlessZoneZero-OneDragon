# 区域巡防

驱动盘副本详情。玩法见[区域巡防](../gameplay/区域巡防.md)。本页记录 iOS 手柄布局，保留原 PC 区域。

## 入口与状态

快捷手册 → 训练 → 区域巡防 → 指定副本的前往 → 传送确认 → 详情 → Start 下一步 → 编队 → 出战。编队和战斗结果使用已有共用画面。准备页 B 返回详情，详情 B 返回大世界。

2026-10-26 实拍手册可见高塔与巨炮、猎人与忠犬、恶拳与凶枪从上到下排列，与原副本数据顺序相反；另一次从大世界进入时，机师与叛甲、怪兽与怪客被推荐置顶，后接迅脊与裂爪。列表不是固定顺序，不能持续按源数据索引决定滚动方向。黄色整行或黄色“前往”表示焦点。

## 区域与可交互元素

| 区域 | 含义 |
|---|---|
| 原副本名称列表 | 原 PC 横向副本文字区，保留 |
| 原电量 | 原 PC 电量区域，保留 |
| 手柄-挑战等级 | 右上挑战等级；实拍 Lv.60，LS 提示 |
| 手柄-下一步 | 右下 Start 下一步，进入编队 |
| 手柄-副本标题 | 中上部当前关卡标题，实拍怪兽二重奏 |
| 手柄-副本列表 | 下方横向卡片，黄绿边框是当前焦点；必须与标题一致 |
| 共用手柄-电量 | 当前电量 / 本场需求，详情实拍 81/60，编队同样读取 |

详情还有 Y 相关代理人、RS 查看奖励、LB 自动拆解与 X 自动战斗提示；本次不修改自动拆解，不用自动战斗道具。难度选择、自动拆解设置页尚未建档。

## 识别证据

`ios_patrol_detail.webp`：标题怪兽二重奏、挑战等级 Lv.60、下一步、81/60，下方有铁律与狂徒、口舌与刀兵、游侠与守卫和选中的怪兽二重奏。`analyze_screen` 同时给出模拟室和区域巡防非精确候选，业务需用独立区域和目标双重核对。

`ios_patrol_arrow.webp`：右翻页箭头会穿过选中框，遮挡约三十像素边线；只对本页面使用 35 像素闭合，模拟室保留 5 像素规则。回放验证箭头两个位置都能识别唯一目标，并拒绝相邻错目标。

`ios_handbook_descending.webp`：手册副本倒序排列，聚焦恶拳与凶枪。测试从此帧查找怪兽二重奏向上移动，旧帧不连续重复发键。`ios_handbook_recommended.webp` 验证推荐项置顶时先向下遍历；边界连续三轮不动允许反向一次，第二次到边界失败，不无限循环。

`ios_patrol_next_split.webp`：较宽的下一步区域会将文字识别为“下一”“步”；区域收紧到文字周围后，两种像素密度的原截图经实际 OCR 服务均通过，未降低匹配阈值。
