# 恢复电量

副本内电量不足时,点「下一步」/「再来一次」触发的恢复弹窗。用**储蓄电量 / 以太电池 / 菲林**兑换电量,补到副本需求。`RestoreCharge` op 处理(按 `restore_charge` 配置选来源)。

## 何时出现 + 状态流转

- **入口**:副本入口(实战模拟室画面)点「下一步」电量不足 → 主弹窗;战斗后「再来一次」电量不足 → 主弹窗。
- **流转**:

| 当前态 | 动作 | 下一态 |
|---|---|---|
| 主弹窗 | 选来源(储蓄/电池/菲林)+ 确认 | 快捷使用 |
| 快捷使用 | 调兑换数量 + 确认 | 获得 |
| 获得 | 确认 | 回副本入口(电量补满,可出战) |
| 主弹窗/快捷使用 | 取消 | 回副本入口(电量不变) |

## 识别特征(稳定锚点)

- **标题**:「恢复电量」(主弹窗,`id_mark`)/「快捷使用」(快捷使用子态)/「获得」(获得子态)。
- 取消/确认(通用确认按钮)。

## 可交互元素

| 元素 | 类型 | 备注 |
|---|---|---|
| 类型(来源区) | text(ROI) | 储蓄电量/以太电池/菲林 三选项;`RestoreCharge` 按配置选(仅储蓄/电池,**菲林未支持**) |
| 当前数量 | text(ROI) | 快捷使用子态,来源持有量(如储蓄电量 2400) |
| 兑换数量-数字输入框 | text(ROI) | 默认补到副本需求(如 60-43=17) |
| 兑换数量-加 / 滑块 | 图标 | 调数量,范围 1-240 |
| 确认/取消 | text | 确认恢复 / 取消 |

## 备注

- **菲林来源未支持**:游戏恢复电量有 3 来源(储蓄/电池/菲林),但 `RestoreChargeEnum` 只有 NONE/BACKUP_ONLY/ETHER_ONLY/BOTH(储蓄/电池),不含菲林 —— 应有意(菲林珍贵,不自动消耗)。
- **兑换数量默认补到副本需求**:副本需 60、当前 43 → 默认兑换 17(2026-07-24 实测),非补到上限 240。
- **画面识别串扰**:`标题-获得` text「获得」与「道具处理-获得」相同 → analyze 全局匹配易误识别「道具处理-获得」;`RestoreCharge` 用 `round_by_find_area('恢复电量', ...)` 限定列表不混淆。
- **储蓄电量机制**(快捷使用说明文字):电量 ≥240 时每 18 分钟恢复 1 储蓄电量,上限 2400;消耗储蓄电量获等额电量。
- **`RestoreCharge` 入口节点**会先点「实战模拟室 下一步」或「战斗结果-再来一次」打开本弹窗,故本画面出现前必经副本入口。


## iOS手柄子态

不足详情Start打开“恢复电量”。来源横排为储蓄电量、以太电池、菲林；储蓄图标唯一黄色外框是选中态，说明全文“取出等量储备电量”。A进入该来源“快捷使用”。余额、倒计时均为易变值。

快捷使用显示“储蓄电量×持有量”、兑换数值、范围1至240、A确认/X输入/B返回。当前观察默认数量为本场差额，方向左一次减少1；B取消不使用资源。确认后“获得”电量，再确认回详情。

平台差异提供标题、来源、说明、倒计时、快捷来源、兑换数值、最小/最大、确认及底部提示，保留原PC资源。小字最小/最大分区读取，长行漏读不能作为放行条件。
