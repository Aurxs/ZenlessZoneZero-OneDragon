# 卦象集录

与澄辉坪 NPC 阿朔交互后打开的「卦象集录」每日玩法界面(每日一次,与刮刮卡 / 吼吼饼铺等**同类活动共享领取次数**)。

## 何时出现 + 状态流转

入口:大世界 → `Transport(澄辉坪, 阿朔)` 到位 → `interact(F, press_time=0.2)` → **卦象集录主界面**。

| 子态 | 入口 | 出口 |
|---|---|---|
| 1. 主界面 | `interact(F)` 打开 | 点「区域-获取卦象」("開"字图标)→ 滑动态 / 已领取提示 |
| 2. 滑动获取卦象 | 主界面点获取卦象(当日首次) | `drag_to` 来回拖满 → 领奖确认 |
| 3. 领奖确认 | 滑动完成 | 点「确认」→ 返回大世界 |
| 4. 今日已领取终点 | 主界面点获取卦象(当日已在刮刮卡等同类领过) | 点「确认」→ 返回大世界 |

> 2 / 3 子态(滑动获取卦象 + 领奖确认)**待补** —— 当日已领取看不到滑动流程(2026-07-12 实测今日已在刮刮卡领过,点获取卦象直出「今日已领取」提示)。

iOS 手柄布局直接与阿朔交互后进入主界面，没有前置选项。传送落点阿朔名字左右有尖括号，A 保持 0.2 秒即可打开。主界面底部提示 X「卦象集录」、A「占卜」；A 进入获取卦象画面。该画面原文为「拨动右摇杆以获取卦象」，下方显示 0%—100% 进度，不能套用 PC「滑动屏幕」动作。

## 识别特征(稳定锚点)

- 文字「卦象集录」(主界面底部,红 / 黑色书法字)。
- 「開」字圆形木质主图标(区域-获取卦象)。
- 易变:卦象符号环绕(随机)、当日状态(可领 / 已领)。

## 可交互元素

- **区域-获取卦象**(图形按钮,screen_info area 纯坐标 pc_rect `1318,298 - 1650,640`,中心 ~`1484,469`):「開」字圆形主图标,点击触发获取卦象(当日首次 → 滑动;已领 → 提示)。
- **确认**按钮(今日已领取弹窗,~`950,609`):文字按钮,OCR「确认」。
- 左上角**返回**(通用「返回」模板,~`92,22`)。

### 3. iOS 手柄主界面(source_image: screens/卦象集录/ios_main.webp)

左侧阿朔，右侧「開」字图形与卦象集录牌匾。下方标题「卦象集录」在约 1399,937—1538,979；底部 X「卦象集录」与 A「占卜」在约 1347,995—1592,1025。单独「卦象集录」文字也出现在 X 的历史记录入口旁，应同时核对「占卜」提示，避免混淆界面。

已完成后的主界面代表帧为 `screens/卦象集录/ios_main_completed.webp`：中央由明亮的「開」图形变为木质「闭」封面，下方标题与 A「占卜」仍相同。文字不能区分今日是否已完成，需比较中央封面图案。封面模板取自 1350,355—1570,565，模板搜索区域在四边各留 10 像素余量。

### 4. iOS 右摇杆获取卦象(source_image: screens/卦象集录/ios_divine_zero.webp)

放大的龟形雕塑位于中心，背景被遮罩压暗。下方 OCR 原文「拨动右摇杆以获取卦象」在 828,929—1092,966；「0%」在 936,963—984,1001。进度是易变值；摇杆提示与百分数同时存在才表示仍处于占卜操作画面。完整 OCR 快照保存在同目录 `ios_gamepad_ocr.json`。

### 5. iOS 奖励弹窗(source_image: screens/卦象集录/ios_reward.webp)

中心标题「获得」在 926,403—991,444，物品图标与名称在其下方。该代表帧为「降噪处理母盘」×3，物品与数量属于易变值。单个「确认」按钮在约 816,694—1105,767，当前为黄色填充；底部提示方向键「切换选中」与 A「选择」。背景仍可见阿朔与龟形雕塑，但经过模糊遮罩，不能把背景作为当前可操作界面。

卦象结果可能先短暂出现，再叠加奖励弹窗；A 确认奖励弹窗后再次显示卦象结果页，仍需 A 确认退出。

### 6. iOS 卦象结果(source_image: screens/卦象集录/ios_trigram_result.webp)

中间为龟形雕塑中的三个卦象块，右侧悬挂牌显示本次卦象（代表帧为「平」，属于易变值）。底部左侧 X「解卦」在约 630,930—945,1000，中间 A「确认」在约 975,930—1290,1000，右侧为独立分享入口。最下方说明为「算卦占卜只作娱乐，无关现实不扰生活」。

解卦、确认与娱乐说明可共同区分该页和普通奖励确认；「平」不能作为固定识别依据。解卦与分享是额外入口，退出结果使用 A 确认。

## 备注

- **screen_info 现状**:「卦象集录」screen 只有「区域-获取卦象」area(纯坐标,无 text / template)—— analyze 无法精准匹配,靠 OCR + vision 辅助判定。可考虑加「卦象集录」文字 area 提升精准匹配。
- 与刮刮卡 / 吼吼饼铺共享「同类型奖励」每日次数 —— 当日领过任一,其他点获取即出「今日已领取」提示。
- 待补子态(滑动获取卦象 + 领奖确认)需当日未领取时现场快照。
- 占卜用右摇杆旋转推进，百分数是动态进度；页面识别以固定的摇杆操作提示为准。NPC 姓名随镜头移动，不能把其固定坐标作为入口判据。
