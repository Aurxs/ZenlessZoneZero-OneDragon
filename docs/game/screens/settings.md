# 设置

## 何时出现与状态流转

登录页右侧设置入口、已登录菜单中的设置入口可进入设置。本页描述 iOS 客户端的输入布局子态；触屏和手柄布局的大小、侧栏项目及底部按钮不同。

| 子态 | 入口 | 出口 |
|---|---|---|
| 触屏画面设置 | 触屏菜单的设置齿轮 | 点左侧「输入」进入触屏输入设置 |
| 手柄画面设置 | 手柄模式进入设置 | 选择左侧「输入」进入手柄输入设置；B 返回入口 |
| 触屏输入设置 | 触屏模式选择左侧「输入」 | 点当前「触屏」值展开 UI 布局列表 |
| 触屏 UI 布局列表 | 点输入页第一行的当前值 | 选择「手柄」后立即进入手柄输入设置；没有额外确认弹窗 |
| 手柄输入设置 | UI 布局选择「手柄」 | B 返回入口；修改布局后触屏操作失效 |
| 登录设置 | 登录页右侧设置图标 | 输入页选择手柄后，B 一次回到手柄登录页 |

## 识别特征与可交互元素

- 左侧有画面、输入、声音/触觉、语言、账号、其他。手柄布局在输入下方多出「手柄按键」。黄色填充表示当前侧栏项目。
- 输入页右侧标题为「输入设置」，首行为「UI布局」。下拉框的当前值位于第一行右端，展开的选项位于它下方；不能将选项文字当成当前值。
- 触屏布局中，顶部有返回箭头和「街区」，底部有资源管理、恢复默认。手柄布局底部有 A 选择、B 返回和 Y 资源下载提示。
- 触屏输入页显示镜头灵敏度（拖拽）、镜头自动跟随转动、战斗中可滑动触发按钮、按键位置设置、陀螺仪功能、快捷轮盘设置。
- 手柄输入页显示镜头灵敏度（X轴/Y轴）、镜头旋转反向（X轴/Y轴）、确认/取消按钮交换等项目。
- NEW 标记、当前画质数值和灵敏度属于可变值，不用作画面标识。

### 4. 触屏画面设置（screens/Mac启动/ios_settings_touch.webp）

进入时左侧「画面」黄色高亮，右侧是图像、画质档位、渲染精度等画面设置。左侧「输入」可点击；没有「手柄按键」项目和 A/B 提示。顶部「街区」和底部资源管理、恢复默认与触屏输入页一致。全量 OCR 见同文件的 `ios_settings_touch` 项。

### 5. 手柄输入设置（screens/Mac启动/ios_input_gamepad.webp）

UI 布局当前值为「手柄」，左侧输入高亮，手柄按键项目出现。底部明确显示 A 选择、B 返回、Y 资源下载。全量 OCR 见同文件的 `ios_input_gamepad` 项。该子态和触屏输入页的区域位置不同，当前值与列表选项应分别识别。

### 6. 登录设置子态

登录页进入的设置只有画面、输入、声音/触觉、语言，没有已登录设置中的账号、其他或手柄按键项目。顶部是返回箭头，没有「街区」。触屏输入项目相对已登录输入页更靠下，不能复用固定的点击中心。

## 备注

平台资源 `Mac启动` 集中保存准备阶段所需的区域，不将这些不同子态一起声明为全局精准画面。登录页设置入口与已登录设置入口各有独立素材，不能互相代替；账号登录后的弹窗需要按实际画面另行建档。
