# 专业挑战室

玩法见[专业挑战室](../gameplay/专业挑战室.md)。本页记录 iOS 手柄画面，原 PC 剩余电量与需要电量区域保留。

## 入口和状态流转

快捷手册训练 → 专业挑战室 → 指定 Boss 前往 → 传送确认 → 单 Boss 详情 → Start 下一步 → 编队 → Start 出战。详情没有巡防的横向副本卡片，目标通过完整标题核对。默认等级沿用游戏保存值，实拍恶名·杜拉罕 Lv.55。

B 从编队回详情，详情再 B 到横向 Boss 列表，列表再 B 才返回大世界。不能套用巡防详情直接退出的层数。

## 区域映射

| 区域 | 含义 |
|---|---|
| 原剩余电量、需要电量 | 原 PC 分别识别的电量区，保留 |
| 手柄-挑战等级 | 右上挑战等级与 LS 提示 |
| 手柄-下一步 | 右下 Start 下一步，独立裁剪按钮文字 |
| 手柄-副本标题 | 中上单目标标题，空格可忽略但不得只匹配部分 Boss 名 |
| 手柄-底部模式 | 详情底部特殊模式提示区域；本次普通 Lv.55 无燃竭提示 |
| 手柄-副本列表 | 第二层横向 Boss 卡片，完整黄框为当前焦点，NEW 标签可能截断小段边框 |
| 共用模拟室手柄-电量 | 实际当前/所需电量；详情实拍27/40，编队页也须核对 |

详情中 Y 为相关代理人，右侧弱点、抗性和当前情报属于目标资料；奖励图标不是选中 Boss 的证据。列表底部 RS 奖励详情、Y 相关代理人、A 选择、B 返回。
