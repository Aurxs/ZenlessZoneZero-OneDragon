# 专业挑战室

玩法见[专业挑战室](../gameplay/专业挑战室.md)。本页记录 iOS 手柄画面，原 PC 剩余电量与需要电量区域保留。

## 入口和状态流转

快捷手册训练 → 专业挑战室 → 指定 Boss 前往 → 传送确认 → 单 Boss 详情 → Start 下一步 → 编队 → Start 出战。详情没有巡防的横向副本卡片，目标通过完整标题核对。默认等级沿用游戏保存值，实拍恶名·杜拉罕 Lv.55。

B 从编队回详情，详情再 B 到横向 Boss 列表，列表再 B 才返回大世界。不能套用巡防详情直接退出的层数。

## 区域映射

| 区域 | 含义 |
|---|---|
| 原剩余电量、需要电量 | 原 PC 分别识别的电量区，保留 |
| 手柄-挑战等级 | 右上挑战等级与 LS 提示 |
| 手柄-下一步 | 右下 Start 下一步，独立裁剪按钮文字 |
| 手柄-副本标题 | 中上单目标标题，空格可忽略但不得只匹配部分 Boss 名 |
| 手柄-底部模式 | 详情底部活动说明，如双倍电量消耗、双倍奖励获取 |
| 手柄-燃竭开关 | 奖励区上方燃竭模式、RS提示与ON/OFF，独立于底部活动说明 |
| 手柄-副本列表 | 第二层横向 Boss 卡片，完整黄框为当前焦点，NEW 标签可能截断小段边框 |
| 共用模拟室手柄-电量 | 实际当前/所需电量；详情实拍27/40，编队页也须核对 |

详情中 Y 为相关代理人，右侧弱点、抗性和当前情报属于目标资料；奖励图标不是选中 Boss 的证据。列表底部 RS 奖励详情、Y 相关代理人、A 选择、B 返回。

## 证据与待条件

`ios_expert_detail.webp`：恶名·杜拉罕、挑战等级Lv.55、下一步、27/40。完整标题和40消耗经真实OCR回放确认，错目标拒绝。

`ios_expert_list.webp`：汉斯·蓄能型、恶名·装甲哈提、祸首·通缉打手、聚焦的恶名·杜拉罕。生产流程确认此层再B退出大世界；回放确认不会重复返回。

活动目标详情可出现燃竭开关。ON时RS打开“是否退出「燃竭模式」，恢复电量消耗和奖励产出至正常水平？”确认弹窗；黄色确认按钮为默认焦点，A确认后返回OFF，所需电量从80变为40。明确的退出弹窗可作为中断恢复入口，返回后仍须核对目标及OFF。

代表帧：`screens/专业挑战室/ios_expert_burnout_on.webp`、`screens/专业挑战室/ios_expert_burnout_confirm.webp`、`screens/专业挑战室/ios_expert_burnout_off.webp`。

详情右上LS打开等级下拉，B可关闭而不更改等级。当前实拍可见25、35、45、55四档，当前选中55；见 `screens/专业挑战室/ios_expert_level_options.webp`。这份画面没有燃竭开关，不能据此推断其他账号或版本的开关出现条件。

燃竭模式适用条件（用户补充）：仅部分活动怪物具有此开关，通常位于列表最前两个目标。不能用普通杜拉罕或等级上限推断整个专业挑战室不存在燃竭；检查时优先确认当前列表前两个活动目标。
