## 迷失之地-通用选择

`handle_interact` 识别到此画面后委托 `LostVoidChooseCommon`。是「选 N 个」类选择的**容器画面**,涵盖选鸣徽(藏品)、选卡牌、选武备、选战术棱镜方案强化方向等多种子态,由**顶部标题** OCR 区分(见下表)。

**状态流转**:
- 入口 = 层间移动中交互(感叹号 NPC / 白点 / 下层入口)后,`handle_interact` 精准匹配本画面 → 委托 `LostVoidChooseCommon`。
- 出口 = 选满 N 个 → 点「按钮-确定」→ 返回大世界 → `after_interact`。

**子态(按 `区域-标题` OCR,代码 `check_choose_title`)**:

| 标题文案 | 规则 | 含义 | 需选数 |
|---|---|---|---:|
| 请选择1张卡牌 | CHOOSE_1_CARD | 选 1 张鸣徽/卡牌 | 1 |
| 请选择1个武备 | CHOOSE_1_GEAR | 选 1 个武备 | 1 |
| 请选择2项 / 请选择2枚鸣徽 / 两枚鸣徽 | CHOOSE_2 | 选 2 个 | 2 |
| 请选择1项 / 请选择1枚鸣徽 | CHOOSE_1 | 单选(1.5 后武备/鸣徽都可能) | 1 |
| 获得武备 / 武备已升级 | GEAR_GAIN / GEAR_UPGRADE | 武备获取/升级(无需选,直接确定) | 0 |
| 获得战利品 | ARTIFACT_GAIN | 藏品获取(无需选) | 0 |
| 请选择战术棱镜方案强化的方向 | GEAR_BRANCH | 武备分支二选一 | 1 |

> 标题未命中时,用 `区域-武备标识`(template `common_choose_gear`)兜底判断武备单选。

**识别特征(稳定锚点)**:
- `按钮-确定` — `id_mark=true`,`text=确定`,`pc_rect=[855,795,1165,975]`,`lcs_percent=0.7`(2026-07-26 已收紧,见备注)。
- `迷失之地-TAB` — `id_mark=true`,template `normal_world_tab`,`pc_rect=[0,482,102,600]`(左下角小地图/TAB 图标)。

**可交互元素**:
- 卡牌 / 藏品(中央,横向排列):点击选取;选中态靠 `区域-藏品已选择` OCR「已选择」「有同流派武备」判断。
- `按钮-确定`(下方居中):确认;**多选时按钮文字带 `(x/y)` 计数**(代码 `_get_chosen_count_from_confirm_button` 解析 `(\d+)/(\d+)`)。
- `按钮-刷新`(右上 `[1672,22,1830,76]`,`color_range` 白色)。
- `文本-详情`(左上 `[74,24,142,80]`)。
- 其他区域:`区域-标题` / `区域-藏品名称` / `区域-武备名称` / `区域-藏品已选择` / `中间区域-识别黑屏`(黑屏点击兜底用)。

## 迷失之地-武备选择

`handle_interact` 识别到此画面后委托 `LostVoidChooseGear`。用于选武备 / 开局选初始战术棱镜方案。

**状态流转**:
- 入口 = 第一层(ENTRY)开局选初始武备;或层中交互武备图标后。

- ⚠️ 入口层选完携带后 **NPC 仍可重复交互再次打开本画面**(可反悔换选);游戏交互判定按 角度>距离,
  站在两个相邻 NPC 之间容易再次命中刚选完的 NPC(见 [gameplay 入口层交互机制](../gameplay/迷失之地.md#入口))。
  自动化对策:`LostVoidChooseGear` 传入 `completed_name_list` 时先只点首个武备读名字,命中已完成名单(各画面首个武备名)
  → 直接点返回退出(状态 `重复武备选择`;名单已有 2 个武备名时必为重复,连读名都省掉直接退出);
  `LostVoidRunLevel` 按键前先 OCR 交互文本确认目标,命中已交互 NPC 时朝排除其图标后的剩余感叹号迈步换目标,

## 迷失之地-挑战结果

精英(战斗-道中危机)/ 终结之役(BOSS)战胜利后弹出;记录业绩点 / 周期奖励完成度(`run_record.eval_point_complete` / `period_reward_complete`)。**多子态**(按钮分阶段出现)。

**状态流转**:
- ① **奖励展示态**:标题 + 奖励数字,**无按钮**(`after_interact` 等待按钮出现 — 代码注释「标题出来后按钮还需一段时间才能出来」)。
- ② **确定态**:`按钮-确定` 出现 → `handle_challenge_result_confirm`(连点确定 → 进 `挚交会谈` / 下一层)。
- ③ **完成态**:`按钮-完成` 出现 → `handle_challenge_result_finish`(识别 `奖励-零号业绩` / `奖励-丁尼` 模板判断完成度 → `STATUS_COMPLETE`)。

**识别特征(稳定锚点)**:
- `标题-挑战结果` — `id_mark=true`,`text=挑战结果`,`pc_rect=[581,24,1354,289]`(宽 773,顶部标题区)。

**可交互元素**:
- `按钮-确定`(`[936,855,1338,997]`)+ `按钮-完成`(`[1566,1002,1830,1052]`)。
- `奖励-零号业绩`(template `challenge_reward_eval`)+ `奖励-丁尼`(template `critical_reward_money`),**共用 rect** `[1312,486,1834,834]`。

**状态流转**(`LostVoidLottery`):

- 出口 = `文本-剩余次数` OCR 无正数 → `STATUS_NO_TIMES_LEFT` → 点 `按钮-返回` 回大世界。

- `按钮-奖励预览`(右上)+ `按钮-返回`(左上)+ `按钮-获取确定`(结果领奖,见备注)。

## iOS 手柄：黑底事件文字

source_image: `screens/迷失之地-大世界/ios_narration_continue.webp`

部分NPC事件对话结束后出现全黑背景，中央显示事件叙述，文字下方约(961,577)显示圆形绿色A提示。按A后进入鸣徽等事件结果页；叙述内容随事件变化，不作为固定识别文案。该子态没有底部姓名框，也没有右侧选项列表。

平台区域`手柄-事件文字`覆盖中央文字，`手柄-事件继续`匹配独立A图标（模板`ios_gamepad/lost_void_narration_a`）；需结合全黑背景与实际文字区分普通加载黑屏。中央A可匹配此子态，但并不使整张画面成为精确的“迷失之地-大世界”。
