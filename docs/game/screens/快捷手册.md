# 快捷手册

绝区零**玩法总入口**(绝大多数周期 / 常驻玩法的统一入口)。大世界右上角「快捷手册」按钮进。5 个 TAB(目标 / 日常 / 训练 / 作战 / 战术),每 TAB 列玩法卡片(玩法名 + 奖励进度 + 「前往」传送按钮)。

**为什么重要**:式舆防卫战 / 迷失之地 / 零号空洞 / 危局强袭战 / 咖啡店 / 影像店 / ... 等玩法入口都在这里;app `TransportByCompendium(tab, category, mission_type)` 经此传送。

## 何时出现 + 状态流转

- **入口**:大世界 右上「快捷手册」按钮(~1531,60,需 pc_alt)→ 快捷手册。
- **流转**:选 TAB → 点玩法卡片「前往」→ 传送确认「是否立即传送?」→ 点「确认」→ 传送到该玩法入口。
- **退出**:esc / 左上返回 → 大世界。

**TAB 切换**(顶部,y~161):目标(769)/ 日常(955)/ 训练(1142)/ 作战(1330)/ 战术(1514)。

## 识别特征(稳定锚点)

- **TAB 文字**:目标 / 日常 / 训练 / 作战 / 战术(顶部,稳定;TAB-XX text area)。
- **QUICK ... HANDBOOK**(左上标题)。
- **资源栏**(右上角):三段右对齐数字 —— 电量(3 位,如 240/240)、储蓄电量(4 位上限 2400)、以太电池数(3 位上限)。`ChargePlanApp.check_battery_charge` 运行「电量检测」图像分析流水线:按「快捷手册->以太电池」区域裁剪,再做 HSV 过滤,最后整栏 OCR;取数时以 `/` 分界取左段数字,按检测框中心与三个字段的固定中心锚点比对归位,缺字段补 0。同一栏另有「以太电池」模板 area(battery 图标)。

## iOS 手柄特训目标

训练左栏“特训目标”显示游戏已保存的培养角色，右侧总览列出目标材料与副本。顶部Start为更换特训目标，X为查看攻略；读取目标不需要触发这两个按钮。总览代表帧：`screens/快捷手册/macos_training_overview.webp`。

普通副本分类中，培养目标对应行的“前往”左侧有圆形角色头像；普通推荐行可以有耳机图标，但没有培养头像。头像标记与其上方的完整副本标题关联，不能把所有推荐行都视作培养目标。同一分类可以有多个带头像的目标。区域巡防代表帧 `screens/快捷手册/macos_training_patrol_markers.webp` 中机师与叛甲、怪兽与怪客带标记，第三行无标记。平台区域“手柄-培养头像标记”限定列表的头像列，避免左侧当前角色头像和奖励图标干扰。

## iOS 触屏手册与启动准备

触屏手册顶部仍显示目标、日常、训练、作战、战术，右侧有橙色 X 关闭按钮，未显示 LB/RB 标签提示。代表帧：`screens/Mac启动/ios_touch_compendium.webp`。关闭后回到触屏大世界，可经菜单设置切换手柄布局。

启动适配使用“Mac启动/快捷手册-触屏关闭”模板区域及“快捷手册-顶部标签”文字区域；手柄布局使用自身的返回提示，不能仅凭手册标签推断输入模式。
