# 菜单(主界面)

## 何时出现与状态流转

iOS 触屏大世界点击左上菜单图标后，进入带动态壁纸和底部功能列表的菜单。左上返回箭头回到大世界；底部设置齿轮进入[设置](settings.md)，更多入口进入[更多功能](菜单-更多功能.md)。

## 可交互元素

触屏子态底部从左到右为：更多、勘域编队、邮件、设置、公告、成就、绳网、仓库、代理人、商城、丽都城募、调频。设置入口是齿轮图形，中心约 `(600,950)`，标签文字在下方。左上显示玩家头像、昵称、等级，右上显示资源；右侧是活动卡片列表。

玩家信息、资源数值、动态壁纸、活动卡片和 NEW 标记都可能变化；底部的更多、仓库等功能文字可以作为菜单锚点。

## 备注

iOS 手柄布局的按键提示与触屏不同，不能将触屏菜单的坐标当成手柄菜单操作。手柄导航使用已建档的按键，移动端手柄模式不接受触屏点击。
