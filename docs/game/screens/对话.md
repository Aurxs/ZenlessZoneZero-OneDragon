# 对话(大世界 NPC / 通用)

大世界 `interact(F)` NPC 触发的对话画面,或剧情 / 任务对话。**通用兜底画面**(像加载画面,无固定文字特征):NPC 名不固定,旁白对话甚至不显示 NPC 名。

## 何时出现

- 大世界 `interact(F)` NPC(代理人好感度 / 任务 NPC / 狮耶等)。
- 剧情对话 / 任务对话(主线 / 支线 / 委托)。

## 识别特征(稳定锚点 = 结构,非文字)

- **下方对话框**(固定 UI 结构,非文字)。
- **NPC 名**:在 `好感度标题` area(pc_rect `892,798-1042,836`,底部中央),NPC 名不固定(狮耶 / 代理人 / 任务 NPC);**旁白对话无 NPC 名**(该 area 空)。
- **选项**(可选):`好感度选项` area(`1420,552-1918,804`,右侧);无选项普通对话无。
- ⚠️ **无固定文字特征**(像加载画面)→ analyze 通常无精准匹配(`screens=[]`),靠对话框结构 + `好感度标题` area 判定。

## 可交互元素

- **好感度选项**(右侧 area,有选项对话):点选项推进。
- **对话框确认 / 取消**(`1036,593-1212,657` 确认 / `726,600-918,652` 取消,有按钮对话)。
- **无选项普通对话**:点「菜单-返回」退出(BackToNormalWorld `_handle_agent_dialog`:无选项 → `round_by_click_area('菜单', '返回')`)。

## 识别快照

### 1. 有 NPC 名对话(source_image: screens/对话/有NPC名对话.webp)

- 匹配画面:无精准命中(analyze `screens=[]`);靠对话框结构 + `好感度标题` area 的 NPC 名(OCR「狮耶」`935,802` 在 `892,798-1042,836` 内)。
- 全量 OCR:嗯呢嗯呢呢！…(振兴随便观！…) / 狮耶(NPC 名) / 觀便随(背景招牌)。
- vision:下方对话框 + NPC 名「狮耶」+ 第 3 人称角色背部(面向 NPC)。

### 2. 旁白对话(无 NPC 名)(待补)

- 识别:对话框结构 + `好感度标题` area 空(无 NPC 名)。需现场快照。

### 3. iOS 手柄录像店入口选项(source_image: screens/对话/ios_random_play_options.webp)

澄辉坪录像店营业点交互后，下方为 NPC 对话框，右侧纵向排列「查看经营状况」「暂时不用」。当前「查看经营状况」有整行黄绿色填充，左侧显示 A；未选中的「暂时不用」为深色背景。A 确认「查看经营状况」后进入录像店经营页面，具体页面与营业状态由[影像店营业](影像店营业.md)的画面识别继续确认。

平台沿用「大世界」画面的对话子态，`手柄-对话选项带` 为 `[1340,490,1920,815]`，包含选项及 A 提示。该区域自身是动态文字范围，不作为整个对话画面的唯一标识。原图局部 OCR 读到 A（相对框 `44,164,28,27`）、「查看经营状况」（`139,161,139,28`）及「暂时不用」（`139,240,99,32`）；当前只有「查看经营状况」文字周围存在黄色填充。局部识别快照保存于测试仓 `screens/对话/ios_dialog_crop_ocr.json`。

## 备注

- **无固定特征兜底画面**(NPC 名不固定 / 旁白无):analyze 无精准匹配,识别靠对话框结构 + `好感度标题` area。与「加载画面」同属兜底画面(见 onboarding skill「兜底画面」方法论)。
- screen_info:`normal_world.yml` 好感度标题 / 选项 + 对话框确认 / 取消 area(BackToNormalWorld `_handle_agent_dialog` / `_check_agent_dialog` 用)。
- 退出无选项对话:点「菜单-返回」(BackToNormalWorld)。
