# 恶名狩猎手柄画面

玩法目标见[恶名狩猎](../gameplay/恶名狩猎.md)。PC 区域与动作以原 screen_info、NotoriousHunt 为参考，手柄布局单独建档。

## 快捷手册入口

上方固定标签为目标、日常、训练、作战、战术；训练选中为黄色。左侧分类恶名狩猎选中为蓝色。右上区域标题“本周核心技材料掉落次数”显示当前剩余次数，下面为周期挑战入口与进度，再往下是可滚动的 Boss 列表。底部为 Y 详情、A 选择、B 返回。目标名是匹配用户计划的内容，不作为页面唯一识别依据。

2026-10-26 首帧右列表为库萨里库和基塔布鲁，左分类已选恶名狩猎，右侧尚无黄色焦点。继续 A 进入右列表，按实际黄色外框定位目标；目标变化和滚动后不可沿用旧坐标。传送后进入目标挑战页。

## 可选战斗引导

进入场景后可能出现“战斗引导”弹窗，已见内容为“连携招架”，底部 B 返回。用户确认它并非每次出现，因此只在标题和返回提示可见时处理，不等待它出现、不把具体招式名当必需条件。用户确认须先翻页才能返回：读取当前页/总页数，未到最后一页时按右方向键翻页，到最后一页再按 B；不固定假设始终两页。弹窗遮罩期间不继续移动或出战策略。

## 挑战准备与结果

挑战页右上“挑战等级”下拉框由 LS 打开，方向键上下选择，A 确认；当前等级会同时出现在下拉框标题和菜单选项中。Start 下一步，出战页 X 打开预备编队，Start 出战。

Boss 血条位于画面右上，移动端左端约在 x1132、y44，保留黑色边框和两条横向条带作为模板，不使用 Boss 头像或计数。

结果页标题“挑战结果”，左下目标“完成恶名狩猎”的 1/1 表示通关、0/1 表示失败。下方速度目标、评级和战利品不是必须成功条件。B 完成或 B 退出返回挑战页。

## 周期挑战弹窗与返回

挑战入口左下 X 打开周期挑战，弹窗固定标题“周期挑战”，右上 X 全部领取，底部 A 选择 / B 返回。全部领取文字黄色表示可领；领取后出现通用获得弹窗，A 确认，返回列表后全部领取文字置灰。B 关闭弹窗。

挑战页 B 返回横向 Boss 卡片列表，列表底部有“当期剩余奖励次数 / 奖励详情 / 相关代理人”提示。列表再 B 返回大世界。
