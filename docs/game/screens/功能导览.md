# 功能导览

## 入口与状态流转

手柄大世界同时按 LT 与菜单键，打开右侧 `.FUNCTIONS` 面板。与单独菜单键打开的主菜单不同。方向键移动卡片焦点，A 选择，B 返回大世界。情报板位于 COMMUNITY 分组；确认后进入[情报板](情报板.md)。

## 稳定特征与交互

右上 `.FUNCTIONS` 标题、纵向分组网格和底部 A 选择/B 返回提示。焦点是卡片外沿的黄色边框，NEW 徽章不代表焦点。卡片名称和所在位置须同时核对，不能用固定移动次数选择。

首屏可见商城、音像店、改装店、旅程、后勤商店、攻略、仓库、合作者、站点、情报板、好友、个人主页，下方 GENERAL 分组仍可滚动。这里只记录首屏实拍，不推断未展开功能。
