# 情报板

情报板展示玩家发布的委托。玩家可以接取他人的战斗代行委托，按指定挑战目标完成，再领取贡献点数和站点信度。本次实拍包含专业挑战室和恶名狩猎；困难委托另有目标，不等同于这两类战斗代行。

## 资源与奖励

列表底部显示本周期贡献点进度，当前界面上限为 1000。所测专业挑战奖励为 70 贡献点数、250 站点信度，恶名狩猎卡片显示 100/500；具体奖励以所接委托详情为准。站点信度用于站点成长，不能把它当作普通挑战的绳网经验。

接取后委托进入限时进行状态，详情提供“放弃委托”和“前往”。前往专业挑战室时可见“委托代行中 ON”、本次作战无常规报酬以及电量消耗 00。恶名狩猎在免费奖励次数 0/3 时显示“无报酬模式”；必须与“委托代行中 ON”、深度追猎 OFF 一起核对，不能仅凭次数用完判断当前挑战免费。

## 完成循环

大世界 → [功能导览](../screens/功能导览.md) → [情报板](../screens/情报板.md) → 筛选战斗类型 → 接取并前往 → 指定挑战 → 通关目标 1/1 → 完成结算 → 代行委托完成奖励 → 确认后返回板面。

“挑战结果”标题不能证明胜利，必须核对通关目标。代行模式不领取普通副本材料，奖励出现在单独的“代行委托完成”弹窗。

## 附录：自动化范围

原应用按已保存的当前编队或预备编队、策略和普通/刷经验模式运行，沿用原周期计数。当前实现边界与验收以[开发说明](../../develop/zzz/application/intel_board.md)为准；本页不把待验分支当作已经通过。

信息来源为 2026-10-27 至 28 客户端实拍；未核实发布委托的电量成本、兑换规则、所有站点和困难委托。
