# 区域巡防

区域巡防提供驱动盘等奖励，玩家按所需套装选择对应副本。与模拟室按卡片增加材料消耗不同，本次实拍的普通巡防单场需要 60 电量。

## 资源与循环

从快捷手册训练页选择副本，检查奖励预览与关卡增益，选编队后挑战，胜利领取驱动盘并返回。不同副本对应不同套装；GUI 用套装组合显示名称，游戏详情使用关卡名，例如“折枝剑歌 静听嘉音”对应“怪兽二重奏”。以原副本数据及游戏预览为准，不用单次掉落推断保证奖励数量。

详情展示当前电量与需求，电量不足时不出战。实拍另有自动战斗道具入口和自动拆解设置，二者与正常战斗消耗电量的流程不同，本次未操作。解锁等级、各难度收益、双倍活动与重置周期未在本轮核实。

## 入口与画面

大世界 → 快捷手册 → 训练 → 区域巡防 → 目标前往 → 详情。手柄焦点、按钮和返回路径见[画面说明](../screens/区域巡防.md)。本轮单场使用游戏已保存的默认等级，不切换难度。
