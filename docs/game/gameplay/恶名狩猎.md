# 恶名狩猎

目标是挑战指定强敌，取得代理人核心技能培养材料，并领取周期挑战奖励。入口为快捷手册的训练分类。玩家按所需材料选择目标，战斗胜利后领取对应材料；免费奖励次数和周期挑战成就属于不同进度。

2026-10-26 本机手柄画面显示“本周核心技材料掉落次数：3/3”，周期挑战进度为 0/9。副本列表显示库萨里库、基塔布鲁等目标，每个目标具有独立前往入口。次数和进度以实际画面为准，不将当地时间或上次记录当作本周剩余次数。

免费周期挑战与消耗电量的深度追猎必须区分；本轮迁移只覆盖免费奖励，不因免费次数耗尽自动切到深度追猎。原实现记录每周三次免费奖励，当前客户端入口已显示三次；本机验证失败退出不扣免费次数，胜利一次后 3/3 变为 2/3；周期奖励可一次领取当前已完成条目，不要求先耗尽全部免费次数。不同 Boss 的鸣徽选择仍待实拍。

画面与按键见[恶名狩猎](../screens/恶名狩猎.md)，自动化范围见[Mac 迁移设计](../../develop/zzz/application/macos_notorious_hunt.md)。

## 深度追猎与体力计划

2026-10-26新增实拍：免费奖励已用尽后，可在详情用RS开启深度追猎并确认提示，奖励预览恢复、消耗显示60电量。此模式与无报酬练习不同，不能仅因免费次数为零就开始无报酬挑战。免费机会仍存在时，原体力计划会跳过深度追猎目标，周常任务仍由恶名狩猎应用管理。

体力计划的目标、编队、次数与鸣徽选项来自原GUI；胜利与实际扣电确认后，只增加体力计划完成次数，不减少周常免费次数。剧情未推进完会显示隐藏Boss名，按原数据别名映射为同一目标，不要求玩家补剧情。
