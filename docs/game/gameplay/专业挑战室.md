# 专业挑战室

专业挑战室是按指定敌人选择的养成材料副本。玩家在快捷手册的训练分类选择目标，查看弱点、抗性、当前情报和奖励，再配置编队进行战斗。

本轮实拍恶名·杜拉罕默认Lv.55，普通挑战需40电量；详情的27/40明确表示不足，未进入战斗。不同目标对应不同材料，选择时沿用原游戏目标名称，不用相邻目标替换。消耗和收益以实际准备页及结算为准，不由关卡名称预估掉落数量。

入口和两层返回见[画面说明](../screens/专业挑战室.md)。编队、战斗、结算属于同一轮挑战；胜利才能累加已完成次数。没有通过本次普通关卡测试推断燃竭模式、特殊奖励或解锁条件。

信息来源以2026-10-26客户端实拍和原副本数据为准。背景资料曾把专业挑战室列为核心技能材料来源，参考[17173 VR训练系统介绍](https://news.17173.com/content/04292024/090604827.shtml)；该文较早，本文不沿用其中的解锁次数、等级范围或退款规则。
